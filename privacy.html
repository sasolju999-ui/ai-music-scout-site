Privacy Policy

Effective date: October 27, 2026

Purpose

AI Music Scout is a personal DJ music-discovery utility that uses YouTube API Services. It searches for new music and can add qualifying videos to a YouTube playlist when its authorized user enables that feature.

Data accessed

With Google OAuth permission, the application may access the connected YouTube channel's identifier and basic profile, playlist and playlist-item information, and metadata for videos such as title, channel, publication date, duration and publicly available statistics. It may insert videos into a designated playlist and read existing entries to prevent duplicates. The tool does not ask for a Google password.

Use of data

Data is used to discover and classify music, generate reports, compare available video statistics, prevent repeated suggestions, and manage a listening playlist. It is not used for targeted advertising or sold to others. This application does not publish YouTube videos or send messages as the user.

Storage and sharing

Program data, including video IDs, playlist history, candidate metadata and observation history, may be saved locally on the owner's computer and in the owner's GitHub repository and GitHub Actions artifacts. OAuth credentials are stored locally and as protected GitHub Actions secrets to let scheduled jobs access the authorized account. YouTube and Google process requests needed to provide their API services; GitHub hosts the scheduled automation and associated data. No public disclosure of OAuth credentials is intended.

Retention and deletion

History of videos previously added to a playlist may be retained to prevent those videos from being added again after manual removal. The owner can delete locally stored state, repository files, workflow artifacts and OAuth credentials. Deleting an item from a YouTube playlist does not automatically delete historical records in the application. To request deletion or report a privacy issue, contact the application owner using the developer contact email listed on its Google OAuth consent screen.

Revoking access

You may revoke access at any time in Google Account third-party connections. Revocation prevents further authorized YouTube operations until new consent is granted. Existing local and GitHub records must be deleted separately if desired.

Policies

This app uses YouTube API Services. See the Google Privacy Policy and YouTube Terms of Service.
